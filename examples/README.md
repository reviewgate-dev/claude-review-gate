# Examples

One worked review case: `fix`, one fix pass, then `ship`.

Adapted from a real run. The reviewer's text was not saved, so the round-1 findings are rebuilt from the fix commit and the round-2 nits are illustrative.

Read `01-usage-pacing.md` top to bottom. It follows the order things happen: brief, author summary, round-1 verdict, fix pass, round-2 verdict, log lines.

The findings follow the kit's format. Names, paths and line numbers are generalized.
